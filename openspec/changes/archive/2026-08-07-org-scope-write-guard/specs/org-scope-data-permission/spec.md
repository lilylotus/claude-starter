## ADDED Requirements

### Requirement: 管辖组织范围校验断言
系统 SHALL 提供"校验某个组织 id 是否在当前登录用户管辖组织范围内"的能力，供组织/任职/应用等模块的写操作接口（新增、编辑、启用、停用、删除）复用；该能力 SHALL 基于既有的管辖组织范围解析结果判断：解析结果为不受限制时，任意组织 id 均视为通过校验；解析结果为受限时，只有落在解析结果允许集合内的组织 id 才视为通过校验，其余组织 id（含不存在的组织 id）视为未通过校验。

#### Scenario: 不受限制时任意组织 id 都通过校验
- **WHEN** 当前登录用户的管辖组织范围解析结果为不受限制，对任意组织 id（含 `0`）发起校验
- **THEN** 校验通过

#### Scenario: 受限时管辖范围内的组织 id 通过校验
- **WHEN** 当前登录用户的管辖组织范围解析结果为受限，允许集合包含组织 C；对组织 C 的 id 发起校验
- **THEN** 校验通过

#### Scenario: 受限时管辖范围外的组织 id 未通过校验
- **WHEN** 当前登录用户的管辖组织范围解析结果为受限，允许集合不包含组织 D 的 id（含 `0` 代表的顶级虚拟节点、或任意不在允许集合内的真实/不存在组织 id）；对该 id 发起校验
- **THEN** 校验未通过
