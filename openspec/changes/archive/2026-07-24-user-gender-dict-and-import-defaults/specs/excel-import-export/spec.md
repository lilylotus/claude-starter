## ADDED Requirements

### Requirement: 非必填的数值类型字段留空时使用默认值而非判定失败
系统在批量导入时把 Excel 单元格值绑定到对应业务模块的创建/更新请求对象上，若某一列在导入字段配置中被标记为非必填、且该列对应请求对象上的属性是数值类型（如显示序号），则该单元格留空时 SHALL 不将该属性强制置空，而是保留请求对象自身声明的默认值，不因此判定该行失败；该列被标记为必填时，留空仍 SHALL 按既有的必填校验规则判定该行失败。字符串类型的属性（如备注、扩展字段）留空时的既有处理方式（显式清空）不受本条影响。

#### Scenario: 非必填的显示序号列留空时使用默认值
- **WHEN** 批量导入某个 `bizType` 的一行数据，"显示序号"列在导入字段配置中为非必填，且该单元格留空
- **THEN** 系统成功处理该行，新增或更新后的记录"显示序号"取请求对象声明的默认值（如 `0`），该行不被计入失败明细

#### Scenario: 必填的数值列留空仍判定失败
- **WHEN** 批量导入某个 `bizType` 的一行数据，某数值类型列在导入字段配置中为必填，且该单元格留空
- **THEN** 该行被计入失败明细，原因说明该列不能为空

#### Scenario: 字符串类型字段留空仍按既有方式清空
- **WHEN** 批量导入的一行数据中，某个字符串类型的非必填列（如备注）单元格留空
- **THEN** 系统仍将对应记录的该字段更新为空，行为与本条改动之前一致
