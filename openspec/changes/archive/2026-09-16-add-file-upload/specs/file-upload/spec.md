## ADDED Requirements

### Requirement: 文件上传并落盘落库
系统 SHALL 提供一个文件上传接口，接收 `multipart/form-data` 形式的单个文件，将文件内容保存到磁盘的文件保存根目录下（默认目录名 `upload`，根目录可通过配置项调整），并在文件上传表中新增一条记录后返回该记录的 id 等信息。

保存到磁盘的文件名 SHALL 使用随机字符串加上原始文件的后缀名生成（原始文件没有后缀名时，保存文件名也不带后缀），不 SHALL 直接使用原始文件名作为磁盘保存文件名，以避免同名文件互相覆盖、避免直接暴露原始文件名。

新增的文件上传记录 SHALL 至少包含：原始文件名、保存在目录中的文件名、文件大小、状态。记录创建时状态 SHALL 为"正常"。记录 SHALL 同时写入创建人、创建时间、更新人、更新时间四个审计字段。

#### Scenario: 上传文件成功
- **WHEN** 调用上传接口并携带一个合法的文件
- **THEN** 文件内容被写入到文件保存根目录下，文件上传表新增一条状态为"正常"的记录，接口返回该记录的 id

#### Scenario: 保存文件名与原始文件名不同
- **WHEN** 上传一个原始文件名为 `报表.xlsx` 的文件
- **THEN** 磁盘上保存的文件名是"随机字符串 + `.xlsx`"的形式，而不是 `报表.xlsx`；文件上传表记录中原始文件名字段保存的仍是 `报表.xlsx`

#### Scenario: 未携带文件时上传失败
- **WHEN** 调用上传接口但请求中没有文件内容
- **THEN** 接口返回参数校验错误，不产生任何磁盘文件或数据库记录

### Requirement: 按文件表 id 下载文件
系统 SHALL 提供一个下载接口，按文件上传表的 id 查找对应记录，仅当记录存在且状态为"正常"时，才从磁盘读取该记录对应的保存文件并作为响应内容返回给调用方，响应中 SHALL 携带原始文件名信息（供客户端保存文件时使用）。

当记录不存在、或记录状态为"失效"时，下载接口 SHALL NOT 返回文件内容，SHALL 抛出明确的业务异常，由全局异常处理统一返回错误响应。

#### Scenario: 下载正常状态的文件
- **WHEN** 调用下载接口并传入一个状态为"正常"的文件记录 id
- **THEN** 接口返回该文件的原始内容，且响应中能获取到原始文件名

#### Scenario: 下载失效状态的文件被拒绝
- **WHEN** 调用下载接口并传入一个状态为"失效"的文件记录 id
- **THEN** 接口不返回文件内容，抛出业务异常并提示文件已失效

#### Scenario: 下载不存在的文件记录
- **WHEN** 调用下载接口并传入一个不存在的文件记录 id
- **THEN** 接口不返回文件内容，抛出业务异常并提示文件不存在
